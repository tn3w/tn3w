- **[iplore](https://github.com/tn3w/iplore)**: location, operator and abuse data for any IP, from one offline file
- **[ProtonVPN-IPs](https://github.com/tn3w/ProtonVPN-IPs)**: every ProtonVPN exit and entry IP, daily
- **[flask-Vouch](https://flask-vouch.tn3w.dev/)**: bots get a challenge, people get through
- **[YouTube LevelUp](https://addons.mozilla.org/en-US/firefox/addon/youtube-levelup/)**: no Shorts, dislikes back, sponsors skipped
- **[uaid](https://github.com/tn3w/uaid)**: identify 4,500+ crawlers by user agent
- **[libcaptcha](https://github.com/libcaptcha)**: bot checks without puzzles
